# NYAMPE
### A Web-Based Urban Travel Recommendation Platform

**NYAMPE** is a student innovation project focused on helping people navigate unfamiliar urban environments through clearer travel recommendations.

The project aims to make urban journeys easier to understand by presenting travel options based on estimated cost, travel time, and convenience.

## Project Overview

NYAMPE was primarily developed as a UI/UX design project, with its main design process and interactive prototype created in Figma.

This repository contains an **early-stage HTML/CSS implementation** of the NYAMPE website, developed to demonstrate the initial design concept and explore how the proposed interface could be translated into a web experience.

The current implementation is a preliminary prototype and does not represent a fully developed transportation platform.

## Design Focus

The primary focus of the project is the design and prototyping of a mobile-first website, including:

- User-friendly journey search interface.
- Travel recommendation presentation.
- Estimated cost and travel-time comparison.
- Clear visual hierarchy and navigation.
- Step-by-step journey guidance concepts.
- Visual identity based on the NYAMPE brand design system.

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Ensure that the required assets are available in their referenced locations.

No backend setup is required for the current preliminary prototype.

## Current Limitations

The current implementation is an early-stage demonstration. Depending on the implemented features, it may use simulated content and does not necessarily include:

- Live GPS tracking or real-time navigation.
- Integration with public transportation APIs.
- Verified real-time fares or schedules.
- A backend database or user account system.
- Production-ready route calculation.

Any simulated journey information should be treated as illustrative rather than verified transportation data.

## Future Development

Future work may include expanding the frontend implementation, improving interactive journey guidance, validating transportation information, and exploring integrations with relevant transportation data sources.

## Project Context

NYAMPE is developed as a student innovation project exploring accessible urban mobility and supporting **United Nations Sustainable Development Goal 11: Sustainable Cities and Communities**.

The project prioritizes understandable travel information and an accessible user experience for people unfamiliar with local transportation systems.
